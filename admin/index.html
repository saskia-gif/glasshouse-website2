How do I get a token?
  1. Go to github.com/settings/personal-access-tokens/new
  2. Token name: anything, e.g. Glasshouse editor
  3. Expiration: 1 year
  4. Repository access: Only select repositories → choose your site repo
  5. Permissions → Repository permissions → Contents: Read and write
  6. Generate, then copy the token and paste it above

The token is stored only in this browser. Anyone using this computer and browser could edit the site, so use a token limited to this one repository, and sign out on a shared machine.
